One sentence explaining the modern internet to a traveler arriving from 1800, built only from things they already know — a road, letters, books, whispered gossip: "Picture a road that carries every letter, every book, and every whispered gossip to any door on earth in the blink of an eye."

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

This writes the sentence to `/tmp/out/entry.txt`.
